# 方法与实现

## 模型身份

采用官方GRAM公开递归核心的项目Maze10适配：100个输入格点、5类动作读出、宽度128、2个共享Transformer块、潜变量32维、16次外层递归。
这是在Maze10上新初始化训练的任务模型，不是官方发布的Maze预训练权重，也不是先前自建GRU。
适配点：没有puzzle-ID嵌入；halt head读取首格状态；ACT正确性为最短合法路径；注意力用已验收PyTorch SDPA与reshape修正。
源快照与修改清单见`third_party/README.md`。原核心的no_grad/detach保留，没有扩大反向展开。

## 同监督对照

Q = native ACT batch-sum loss / 2 + mean shortest-DAG probability-mass loss。
这里2为实际微批地图数；4个微批的总loss再除以4累积梯度。原生项的batch归约与DAG项的逐图平均均保留，不把它们省略为任意等权求和。
native loss保留stablemax监督、halt loss与KL balancing(alpha=0.8, KL系数0.1)。
原生监督使用训练答案条件后验；额外K32分支只输入题目，使用先验，参考答案仅进入评分/损失。
先验分支16次外层，只有最后一次外层参与反传，内层保持原梯度截断。

完整最短路径参考j对轨迹i的分数C_ij为该路径各动作log概率之和；保留5类归一化中的null概率。损失按路径长度L归一。

- Multi：Q − 0.1 mean(C)/L，各轨迹独立均匀学习同一参考池。
- Set：Q − 0.1 sum(A*C)/L。A由C/0.5开始，交替行/列log归一化12次，停止A梯度。

目标行边际1/32、列边际1/M；有限迭代只保证实测边际，不能假设已精确双边平衡。记录行/列误差与总质量。
M=1时Multi/Set逐值逐梯度一致；零参考在通用辅助函数中保留零项，但本训练入口拒绝无有效完整参考的题并报错。
M<32允许不同轨迹分配同一参考，不把重复使用当新identity。M>32按固定轮换子集使用，非模型分数选样。

## 推理与读出

先验独立随机候选、K32、16外层、逐格argmax；不修复、不重采样、不使用验证器筛选、不跨轨迹通信。
路径选答取模型自身走过位置的平均所选动作log概率最大者，平局取最早槽。其遍历不检查墙/最短距离，不给予成功奖励；null、越界、重复格时停止记分。
评价checker随后检查合法性和最短性。H是至少一个最短候选，选答正确率不是H，也不是oracle。
旧全图读出另报；公开适配的grid读出在当前精度logits上计算，若比较历史保存BF16与原FP32读出需注明数值来源。

## 指标

U=不同最短路径数；U_all=全部不同合法路径数。
V_target=最短候选数，D_target=V_target−U；V=合法候选数，D=V−U_all。
首条=第0候选是最短路径；合法率=V/K；H=1[U>0]；路径选答=固定无工具规则选中的候选最短。
U=H+(U−H)是计数恒等式，不是机制因果分解。集合差仅相对有限候选池，不表示模型永远不会生成或永久遗忘。
