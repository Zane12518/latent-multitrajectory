## 保存预测、保存统计和重新生成的区别

1. **新生成**：仅上述四个真实权重的小批，以及合成 smoke。
2. **本次重算**：已保存每题数字数组、K 曲线和新增/丢失/保留计数。逐 RNG、逐题核验 `U=V_target−D_target`、`U_all=V−D`、新增减丢失等于覆盖差。没有从计数还原不存在的 identity。
3. **复用旧验收**：portable_v4 在 PyTorch 2.4 CPU 的 24 模型前向与原件相等；各任务一个完整 RNG 原生预测全部字段和集合相等；24 个状态的 CPU 组件读回（零更新）。这些是旧回执，不写成本次新做。
4. **未做**：原始三 RNG 全量 logits/identity 新回读、完整 CUDA 候选再生成、原同时区间再抽样、从头训练、CUDA 连续/保存恢复。当前原完整 checkpoint/数据/预测所在存储不在工作入口挂载范围内；不将不可访问记成结果缺失为零。
