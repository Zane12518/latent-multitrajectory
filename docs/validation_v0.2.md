## 分清验证层次

- 测试覆盖输入／参考内容改变、配置改变、缺状态、显式分叉、legacy 警示，以及恢复后下一更新逐值一致。恢复时复制 Adam 状态，避免后续更新改动传入的 CPU 内存快照。
- GRU 发布的是已有汇总数字及全部条件表，验证导出与表间恒等式；未公开该宿主逐题预测，未重算它的题目 bootstrap 或重训模型。
- GRAM 六组表从已有公开逐地图指标重算，不能称为重新生成全部 1,200 图预测。
- Demo 是保存结果回放。生成 HTML 与数据验证不等于浏览器交互全覆盖。
- GPU、跨设备精确恢复、完整 9,000/1,000 步训练均未在本轮执行；历史相应小批记录另列。
- 自动文本扫描检查明确的秘密／路径模式；它不能证明不存在所有类型的敏感信息，还需人工审阅新增差异和拟推送提交。
- 非代码资产许可维持不变；验证下载不等于授予复用权利。
