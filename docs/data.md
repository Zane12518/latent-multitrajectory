# 数据与监督边界

## 随仓库的小样例

`scripts/make_toy.py`生成4张10×10合成地图，各有6条最短路径。仅用于训练/推理/恢复工程测试，不是论文测试人口。
`data/demo_replay.json`是实验结果回放：固定取历史测试人口前4个地图序号、第一评价重复、全部12个固定端点。没有按方法胜负挑样例。
项目数据公开发布已获批准；非代码许可范围见 ../ASSET_TERMS.md。

## 完整项目人口（独立发布包）

| 划分 | 地图数 | 用途 |
|---|---:|---|
| train | 6,736 | 训练/构造参考/质量目标 |
| selection | 64 | 已登记训练侧选点；不参与本固定终点表的重新选型 |
| test | 1,200 | 完整测试评分，已参与方法开发 |

这不是官方Maze榜单。编码：1地面、2墙、3起点、4终点；100格固定行优先序。输出类0=null，类1/2/3/4=上/下/左/右。
完整答案identity是实际走过的格点路径，不是整张动作网格。未访问位置的变化不计新解。
训练参考为已保存最短路径池；每次辅助项最多取32条，以题号与访问次数确定轮换；Multi/Set使用同一选择规则。
共同质量项用完整最短路DAG计算质量，不受32条参考截断。因此不能称“整个训练只用32条解”，也不能称全部合法路径覆盖率。

完整数据随`latent-multitrajectory-assets.tar.gz`提供，通过 GitHub Release 提供，链接见 README。
`release_assets/data/{train,selection,test}.json`为解包后的约定位置。必须保留数组顺序及题号：评价随机键使用版本内地图序号，不能排序后冒称相同随机表。
重复输入、最短性、参考合法性和划分交集在候选验收报告中单列。项目数据公开已获批准；生成器的原始完整环境尚未重建，不把新生成地图称作旧人口精确复现。
