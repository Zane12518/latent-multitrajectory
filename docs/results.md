## 强对照与范围

Multi 和 Set 共享原生监督/KL/ACT + 完整最短路径 DAG 概率质量、同一最多32参考子集、0.1辅助系数与1000步线性衰减续训。
质量起点训练9000步；source1301与1501为不同初始化，但能力不同，不作简单独立重复平均。
自然 ACT 的实际接纳/重置受模型输出影响，名义数据供给一致不等于实际监督曝光完全相同。
模型546,882参数；每次正式更新4个微批×2地图，先验分支每图32轨迹。每次先验生成16外层、32个高斯随机节点。
同更新和K并非完全等FLOPs或同墙钟。账单未知，不以平台跨度估算。

## 其他已知边界

- 历史自建GRU在SATLIB/Maze上的集合增益属于不同宿主，未计入本表或改名为官方GRAM成绩。
- 官方GRAM NQ10历史Set−Multi增量未确认；不能用Maze正例替代跨任务验证。
- 现代SAT宿主基座能力不足，Graph存在质量停止；不将未执行单元填零。
- 较低0.05辅助系数后续试验未建立一致改进；本候选保留0.1已验收配方，不按测试挑最佳系数。
- 本仓库训练期集合分配没有部署时跨轨迹通信。历史Frozen Base + learned Mixer是另一条研究线，见[release_scope.md](release_scope.md)。
