# 发布范围

本次发布官方 GRAM 递归核心的项目 Maze10 适配、Multi/Set 训练接口、固定预算评测、12 个推理端点及6个配对续训起点。全部六组固定端点结果保留；两个质量初始化不写成六个独立起点。

集合分配发生在训练期间，不是推理期通信。历史 Frozen Base+Mixer、GRU、粒子和其他任务研究不混入本次主表。CPU 工程样例、GPU 小批核验、保存统计复算与完整重新训练的范围分别说明。

源码采用 MIT，非代码资产见 ../ASSET_TERMS.md。公开文件不含内部文档链接、个人目录、内部调度配置或原始平台日志。

## v0.2 增量

新增默认严格恢复、显式分叉与历史兼容、CPU CI、GRU 两任务及有限参考的脱敏报告和聚合统计。历史段落的“本次主表”对应 v0.1 GRAM 主线，不将新 GRU 报告混入。

本次不新增 GRU、Mixer、SATLIB 原始数据或历史权重的公开分发；这些资产仍待身份、许可和干净运行审核。旧 v0.1 文件、原始科学结果、历史验证回执与当前 Demo 保留。详细状态见 [证据索引](evidence_index.md)。

## v0.3 GRU 增量

公开独立自建GRU推理、目标和评测模块、对应配置及复现说明，另以Release提供24个纯推理权重与4个逐题数字文件。逐项来源、许可和校验见[GRU发布范围](gru/publication.md)。此前v0.2“未公开GRU权重”的表述是历史版本状态，不回写旧Release。

保留既有17测试、24加载、48小批原函数对照和保存数组复算的真实范围；不称已重训全部实验，也不称CUDA完整恢复通过。两个宿主的结果分表、训练期Set与推理通信分开。SATLIB原始数据、完整训练人口、原GRU续训状态及127个历史权重不在包中。
