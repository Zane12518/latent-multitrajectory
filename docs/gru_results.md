# 自建 GRU：集合分配的匹配证据

## 结果入口

SATLIB UF20-91（布尔约束满足，完整 1,000 题）与项目 Maze10（最短路径规划，完整 1,200 图）各有 **3 个质量起点 × 2 条续训流**。Set 相对匹配 Q-multi 的六个覆盖同时区间均为正，三项质量保护均通过。

| 任务 | Q-multi U32 均值 | Set U32 均值 | 描述性平均差 |
|---|---:|---:|---:|
| SATLIB | 2.583667 | 2.978611 | +0.394944 |
| Maze10 | 6.098565 | 7.479537 | +1.380972 |

[12 个配对的绝对值、区间与质量表](evidence/gru/paired_results.md)保留每个条件；不是只公开均值。全部普通控制、低学习率候选、source、K 曲线与合法解新增／丢失见[机器可读索引](evidence_index.md)。

这里是**项目自建递归 GRU**，不是官方 GRAM。结果支持此配置下集合分配相对均匀多参考辅助的额外价值；不证明共享递归优于独立层，也不是推理期通信的收益。公开报告与聚合统计已提供；这些 GRU 的模型实现、配置文件、权重及逐题原始预测仍待发布核验，不能用本仓库 GRAM 代码直接复现它们。

## 模型、数据与训练预算

来源合同：`GRAM-ASSIGN-VALUE-20261111-r1`，补充身份与强控制核查：`GRAM-ASSIGN-FOLLOWUP-20261112-r1`。源实现快照包括 `primary_gru.py`、`objective.py`、`statistics.py`；这是内部快照文件身份，不是已经验证的公共 Git 提交。模型完整架构、依赖、checkpoint 绑定的公开复现审核尚未闭合。

| 项目 | SATLIB | Maze10 |
|---|---|---|
| 质量起点 | 2026110874、2026110898、2026110912，各 step4000 | 2026110877、2026110896、2026111117，各 step6000 |
| 续训 | 每起点 A/B 两流，1,000 新更新 | 同左 |
| 每更新曝光 | 8 题，microbatch 2 × 4 | 同左 |
| 候选与深度 | 训练 K32，8/16 轮交替；正式评价受训 d16 | 同左 |
| 优化 | 保留 AdamW 动量，lr=1e−4，weight decay=.01，clip=1 | 同左 |
| 训练参考 | 完整合法赋值池，最多 198；完整枚举成本不因只选部分辅助参考消失 | 6,736 训练图完整最短路径池，最多 128；不等于全部合法路径 |
| 正式评价 | 1,000 条可满足公式；原生先验 + argmax | 1,200 张项目地图；原生先验 + argmax |

A 恢复原完整状态和后续 8,000 个题目曝光槽；B 先恢复同一状态，再按登记规则置换这些槽并重设潜变量随机流。同起点两流不是两个独立质量初始化。三个评价 RNG 为 2026101201/02/03；先题内平均，不能作为训练重复。历史不可用 SAT 起点 2026110911 的零合法记录保留，不作为缺失条件补零或悄悄替换。

## 方法与强控制

- Q-native：保留历史质量目标。SAT 使用原来保留的至多 32 个合法参考的 log-mass；Maze 使用格点最优动作质量与路径池的负 log-sum-exp。
- Q-mass：SAT 使用完整训练合法池的软概率质量；Maze 使用格点质量和完整最短路 DAG 质量。
- Q-multi：共同 Q-mass + 0.1 × 均匀独立完整参考辅助。
- Set：同一 Q-mass + 0.1 × 轨迹—完整参考软分配辅助。温度 .5，12 次 log-domain Sinkhorn，分配权重停止梯度；按答案／路径长度归一化。

辅助参考去重；M>32 使用与当前模型分数无关的固定轮换窗口；M<32 不复制参考列。M=1 时两辅助项逐值、逐梯度相同，不意味着整个目标等于 Q-mass。有限迭代最终列边际与总质量归一，行边际可能有残差；同为 .1 系数不表示梯度强度相同。

本轮 Maze 完整训练路径池与 DAG 解数一致，原归约下 Q-native 与 Q-mass 数学等价；不能将它们算成两份独立方法证据。历史 native/A 模型缺口仍单列：77 缺同预算预测，96 端点未找到，1117 的历史起点不同。

普通控制也有预登记开发机会：SAT74/A 和 Maze77/A 各臂比较 1e−4、5e−5，训练预算相同。后续 SAT128 selection 选出 `main_sat74_a_multi`；Set 对它 ΔU=+0.516667，同时区间 [+.421758,+.611575]，三项保护通过。Maze64 selection 没有合格普通或 Set 候选，不能从测试分数补选获批赢家。

相对 Q-mass 的边界必须保留：SAT912/A 的首条保护未确认；Maze1117/B 的实际选答保护未确认。因此“全部六组胜过匹配 Q-multi”不等于“无损胜过全部强普通控制”。参见[后续控制表](evidence/gru/strong_controls_followup.json)和[训练侧选择](evidence/gru/selection_followup.json)。

## 指标、选答与统计

SAT U 为不同满足赋值数；Maze U 为不同合法最短路径数，U_all 另计所有合法路径。V 是合法候选数，D=V−U_all；最短目标使用 V_target、D_target=V_target−U，不能混用两套口径。新增／丢失仅是两套有限候选池的集合差，不是理论新解或永久遗忘。

固定无工具选择：SAT 对各位置最大 token log-prob 取均值；GRU Maze 对可通行非终点格点取均值。它不是后来 GRAM 发布包的自身路径置信选择器。没有推理期验证器筛选、修复或跨轨迹通信。

SAT 六组平均 H32 从 67.8167% 到 70.9667%，实际选答从 58.5889% 到 61.2278%；候选供给与选答共同改善，但 H−A 仍有约 9–10 pp。Maze H32 约 99.93%，增量主要是已成功题上的不同最短路径，而非成功率本身。

每任务 2,000 次共享题目配对重采样，种子 2026111241；原可评价比较族 × U/合法率/首条/选答构成同时区间，完整族保存在 `*_paired_family.json`。采用固定 bootstrap 标准差标准化的最大误差，不是每次重估标准差的 bootstrap-t。三项质量下界均严格大于 −.01 才称三项保护通过。点值区间跨零不等于无损。

均值是描述性汇总；固定模型题目区间不包含训练起点、续训流或方法选择的不确定性。测试已参与开发，不是独立确认。

## 验证与发布范围

原终审包含保存指标／比较族的独立进程回读，独立 validator 抽样核验而非重新逐题运行全部模型。当前发布只核对导出字段、表内恒等式和主结果一致性，未重新训练或生成 GRU 预测。聚合表不能单独重建题目级置信区间。

原主轮有 50 个新增已评分端点、6 个复用起点；后续另有 17 个训练端点、13,600 正式更新。平台终态与业务审计分开，真实费用 unknown。[审计范围](evidence/gru/audit_scope.json)保留缺失、工程修复和未闭合状态，原始私有路径与平台信息不公开。
